### 标签编辑器重构（管理员用）🔨

**需求描述：**

管理员在视频页面添加标签时，标签编辑器改为以下布局：

1. **已有标签树**（左侧/上方）：
   - 窗口高度固定，可滚动
   - 用树状图显示所有已有标签
   - 点击标签项进入该层级（不是展开，避免前置空格过多）
   - 点击标签只是选择，不是提交

2. **输入区域**（右侧/下方）：
   - 窗口高度固定，可滚动
   - 输入框在触手可及的位置（手机用户友好）
   - 提供一个按钮代表分级符号「/」，用户点击即可插入，不需要自己输入
   - 考虑为用户输入的分级路径做渲染（例如高亮分隔符）

3. **交互逻辑**：
   - 用户点击已有标签列表中的标签 → 填充到输入框
   - 用户可以在输入框中编辑或直接输入
   - 点击「添加」按钮才真正提交

**设计示意：**

```
┌─────────────────────────────────────────────────────────┐
│  管理标签                                          [X]  │
├─────────────────────────┬─────────────────────────────┤
│  已有标签（可滚动）       │  输入区域（可滚动）          │
│                         │                             │
│  > /动物                 │  当前路径：/动物/狗         │
│    > /狗                 │  ┌───────────────────────┐ │
│      > /哈士奇           │  │ 输入标签路径...  [ / ]│ │
│    > /猫                 │  └───────────────────────┘ │
│  > /植物                 │                             │
│    > /花                 │  建议列表：                 │
│      > /玫瑰             │  · /动物/狗/柯基           │
│                         │  · /动物/狗/金毛            │
│                         │                             │
│                         │  [添加]                     │
└─────────────────────────┴─────────────────────────────┘
```

**技术设计：**

- 前端：重构 `Video.vue` 中的标签编辑器对话框
  - 左右分栏布局（flex）
  - 左侧：已有标签树（根据当前输入动态筛选显示）
  - 右侧：输入框 + 建议列表 + 添加按钮
  - 输入框旁添加「/」按钮，点击插入
  - 路径渲染：用不同颜色或样式显示分隔符「/」

- 数据流：
  - 用户输入时 → 筛选匹配的标签 → 显示为树状结构
  - 用户点击树中某项 → 设置为当前路径前缀
  - 用户继续输入或点击建议 → 组合完整路径
